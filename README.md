<br/>

A cybersecurity-focused QR scanner app engineered to catch phishing and malicious QR payloads before a user ever opens them.

- 🏗️ Owned the **end-to-end architecture diagram** for the system

- 🎨 Built the **"Cyber Dark" design system** — deep navy, gold, and cyan — including logo and UI kit
- 📊 Produced the UI/UX case study deck used to present the product

**Focus areas:** Threat detection · Mobile-first UI/UX · Secure system design

</details>

<details>
<summary><b>🔍 XSS Finder — Web Vulnerability Scanner (evolving to Wolf2XFinder v2.x)</b></summary>
<br/>

A lightweight Python-based scanner built to identify Cross-Site Scripting vulnerabilities across live web applications.

- 🕷️ Automated **crawling** of target applications to map attack surface
- 💉 **Payload injection engine** for Reflected, Stored, and DOM-based XSS
- 🌐 **Selenium-driven browser automation** to catch DOM-based XSS that static scanners miss
- 🔄 Actively evolving into **Wolf2XFinder v2.x** with expanded detection coverage

**Tech:** Python · Selenium · Web Security Automation
🔗 **Repo:** [github.com/raghul692/xss_finder](https://github.com/raghul692/xss_finder)

</details>

<details>
<summary><b>🛡️ CyberShield Pro — AI-Powered Security Awareness Platform</b></summary>
